# **App Name**: DeckTap Suite™

## Core Features:

- Image Upload & Link Assignment: Allow users to upload 3-5 images and create a stack/deck of rotate able cards.
- Tap-to-Transition: Implement tap-to-transition functionality where the user can select their transition style (Flip Down, Flip Behind, Slide Fade, Lift Up/Drop Down, or Flip + Dissolve). The whole card is the tap target, with a small icon to open the assigned link.
- Share & Embed: Generate a shareable link for the created card sequence and offer an optional iframe embed code.

## Style Guidelines:

- Deep forest green to create a sophisticated and luxurious feel.
- Gold for highlights and interactive elements, adding a touch of elegance.
- Use Anton or Impact font for headings and key text elements to convey a bold and modern style.
- Maintain a centered, stacked card layout to preserve the cohesive 'deck' aesthetic.
- Employ smooth, subtle transitions like 'Flip Down,' 'Slide Fade,' or 'Lift Up/Drop Down' using CSS3 animations or GSAP to avoid jarring effects.
- Use a simple link icon (e.g., a chain link) or QR code icon to clearly indicate the tap target for opening the assigned URL.
